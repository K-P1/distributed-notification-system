## 🚂 **Railway Deployment Steps**

### **Step 1: Create Railway Project**

1. **Visit Railway**: Go to [railway.app](https://railway.app)
2. **Login**: Use GitHub account for seamless integration
3. **New Project**: Click "New Project"
4. **Deploy from GitHub**: Select your repository `K-P1/distributed-notification-system`

### **Step 2: Configure Service**

1. **Select Service Path**:
   - Root Directory: `/services/template-service`
   - Build Command: `npm ci && npm run build`
   - Start Command: `npm run start:prod`

2. **Environment Variables**: Railway will automatically detect from `railway.json`

### **Step 3: Add Database Services**

#### **PostgreSQL Database**

```bash
# Railway will provide these automatically
PGHOST=<auto-generated>
PGPORT=<auto-generated>
PGUSER=<auto-generated>
PGPASSWORD=<auto-generated>
PGDATABASE=<auto-generated>
DATABASE_URL=<auto-generated>
```

#### **Redis Cache**

```bash
# Railway will provide these automatically
REDISHOST=<auto-generated>
REDISPORT=<auto-generated>
REDISPASSWORD=<auto-generated>
REDIS_URL=<auto-generated>
```

### **Step 4: Deploy!**

1. **Connect Repository**: Link GitHub repo
2. **Add Services**: Add PostgreSQL + Redis from Railway marketplace
3. **Deploy**: Railway auto-deploys from main branch
4. **Get URL**: Note the production URL (e.g., `https://template-service-production.railway.app`)

